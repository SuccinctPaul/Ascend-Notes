# Ascend NPU Knowledge Base

> A newcomer-friendly NPU knowledge base, centered on the **Ascend NPU**.
> Goal: help you grow step by step into a professional NPU developer.

This knowledge base is distilled from the **Ascend-Notes** repo
(a multi-DSL GEMM learning project). It is organized into three sections,
navigable from the left menu:

1. **NPU Architecture**
2. **LLM Optimization Operators**
3. **Performance & Profiling**

> 💡 The primary authoring language is Chinese. Pages without an English
> translation currently fall back to the Chinese source. English translations
> are added incrementally as `.<locale>.md` files (e.g. `index.en.md`).
